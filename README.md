## 01 — Selected work

### .Connecter
**職場の声を、対話と次の一歩へ。 / From employee voices to shared understanding.**

匿名の「今日のひと息」や議題への意見を集め、AIサマリー・テーマ分類・振り返りで、組織の対話を支えるWebアプリを開発。

A workplace dialogue app I developed, bringing together anonymous check-ins, topic-based feedback, AI summaries, and reflection.

**Role** — 開発 / Development · **Preview** — 公開モック / Public mock

[体験版を開く / Try the mock ↗](https://dotconnecter.jp/)  
入口の「モック版をはじめる」→「ふりかえり」で、サンプル議題のAIサマリーと分類を確認できます。  
Choose “モック版をはじめる” → “ふりかえり” to explore sample discussions and summary views.

### L-デザイン for 健康経営
**健康経営を、記録から改善まで。 / Workplace wellbeing, from records to action.**

企業の健康経営を支える業務プラットフォームを開発。宣言・計画・実行・評価・改善をつなぎ、6軸の比較、従業員サーベイ、申請準備の状況を一つの流れで扱います。

A workplace health-management platform I developed, connecting planning, activity records, benchmarking, employee surveys, and application preparation.

**Role** — 開発 / Development · **Status** — ベータ版 / Beta

[サービスを見る / Website ↗](https://portal.ikigai-field.jp/) · [登録不要デモ / No-login demo ↗](https://portal.ikigai-field.jp/app/demo)

デモは架空データ・閲覧専用です。現在の改善アドバイスはデータに基づく定型提案で、AIによる個別提案は準備中です。  
The demo uses fictional data and is read-only. Current guidance is rule-based; personalized AI recommendations are in preparation.
